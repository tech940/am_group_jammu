EVIDENCE: lib/analytics/gtm.ts:53-54 does window.dataLayer.push({event, ...params}). That shape is the GTM contract. gtag.js only acts on entries pushed through gtag() (an arguments object). So adding the GA4 script alone would record page views and nothing else - no view_item, no generate_lead.

One rule to prevent double counting: when NEXT_PUBLIC_GTM_ID is set, GTM owns GA4 (do not render ga4.tsx and do not call gtag from pushEvent); when it is empty, the direct path is used. Write that rule as a comment at the top of gtm.ts. Strip phone_number and email_address from what is forwarded (link-tracker.tsx:58,77 send the dealer's own numbers, which is harmless, but keep one 'no contact details to GA' rule).
