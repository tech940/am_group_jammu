# Frontend Craftsmanship Rules (AM Group Jammu)
- **Skill Reference**: `.agents/skills/frontend-craftsmanship/SKILL.md`
- **Banned**: Dark mode + gold templates, kickers above headings, card-in-card nesting, hover image scaling, hairline codex grids, decorative pulsing dots, `lucide-react` imports.
- **Mandated (since 2026-11-16, owner's instruction: "try this colour combination and use the 60-30-10 rule", from a reference of Oat Milk 60% / Forest Green 30% / Tomato Red 10%)**: the token set in `DESIGN.md` §Oat, forest, tomato / `app/globals.css`. **60% oat** - the grounds: `ground #F3ECDF`, `ground-2 #E8DFCD`, `surface #FFFCF6`. **30% forest green** - structure: the `deep` tokens (`#24523D`, `#1B4130`) for the header, footer, bands and the Buy tile, and the `accent` token (same green) for links, chips, badges and selected states. **10% tomato** - the `pop` token (`#D63A20`, white label, 4.68:1) for the thing to press and nothing else. Ink is a green-black `#14241C` (text only, never a ground). On a green ground the loud control is white. No black or graphite ground, and no blue: the blue palette of 2026-11-14 is retired. Minimum 11px font floor, minimum 14px body floor, WCAG 4.5:1 contrast on all text, and 0 TypeScript compilation errors.
- **Keep the proportions.** Tomato is spent on primary buttons, the header Enquire and a few small marks (`text-pop-text`, pale `bg-pop-bg` discs). Do not use it for badges, links, headings or bands; do not add a fourth colour. The reference tomato `#F2462E` is 3.69:1 under white, which is why the fill is deeper - do not lighten it.
- **Do not write `bg-ink`, `bg-black` or a dark scrim.** A coloured ground is `bg-deep` / `bg-deep-2` (forest green).
- **Radius**: `0` for bands and dividers, `8px` controls, `14px` surfaces, `18px` overlays. Do not write a literal radius.
- **Glass is LIGHT.** `.glass` / `.glass-bar` / `.panel` are white frosted panels (80% white + blur) and re-point the `on-deep` / `accent-bright` tokens to their light-ground partners for everything inside them, so content written for a blue ground stays legible in a panel without edits. `.glass-blue` is the header (the class name is historical; it is green now, and the logo is white artwork). `.photo-scrim` is a green wash. Glass goes over a photograph under the blue wash or over `.sky-ground`; keep the `@supports` and `prefers-reduced-transparency` fallbacks; glass inside glass renders as a plain bordered surface.
- **Illustrations**: the site's own spot illustrations live in `components/system/illustrations.tsx` (flat shapes in the accent green, 2.5px rounded ink outline, objects only, no characters, four CSS variables for colour). Add to that set in the same grammar; do not import an illustration or icon library, and do not copy another site's artwork. One exception, at the owner's request (2026-11-15): the sell page uses the company's own evaluator drawing and dealership logos from its valuation app (`public/sell/`, `public/brand-logos/`).
- **Palettes rejected earlier; do not propose them again.** The blue-and-teal set of 2026-11-14/15 was replaced by the owner, not rejected for a defect, but is not to be brought back unasked. Note the last item below is forest + BRASS on off-white: the current oat + forest + TOMATO is the owner's own choice and is not that palette. `#F8FAFC`/`#0F172A`/`#2563EB` (this file's original mandate), navy `#133A63` + scarlet `#C13A2A`, and off-white + forest `#1B3A32` + brass `#B08442`. The first two are exactly what a design catalogue returns for "automotive dealership" and "luxury brand", which is why they read as generic. The catalogue is not the authority on this project.
